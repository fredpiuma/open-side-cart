# Changelog

## 1.0.0 — 2026-09-30

- First release of the Open Side Cart fork, based on Woocommerce Side Cart Premium 4.9.1.
- Removed license activation, remote updater and usage-tracking code.
- Renamed prefixes, text domain and options to `osc` / `open-side-cart`.
- Load Masonry from the bundled copy instead of unpkg.com.
- Declared GPL-2.0-or-later and added credits for upstream and third-party libraries.
